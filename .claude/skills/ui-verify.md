# Verify UI in Browser

1. Ensure dev server is running (`npm run dev` in `frontend/`)
2. Navigate to `http://localhost:3000/` using chrome browser tools
3. Take screenshots of affected sections
4. Test both light and dark mode (click theme toggle)
5. Scroll through the full page to check for visual regressions
6. Report findings with screenshots
