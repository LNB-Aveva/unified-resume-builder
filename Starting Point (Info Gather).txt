### 5. Create a Basic FastAPI Entry Point

```bash
cat > backend/app/main.py << 'EOF'
"""
main.py - Entry Point for the Unified Resume Builder API

This file is the "front door" of your backend application.
When you run the server, this is the first file that executes.

WHY FastAPI?
- Automatic API documentation (Swagger UI)
- Built-in data validation
- Async support for handling many requests
- Type hints make code self-documenting
"""

# Import FastAPI framework
from fastapi import FastAPI

# Import CORS middleware to allow frontend to talk to backend
# CORS = Cross-Origin Resource Sharing
# WHY: Without this, your React app (localhost:3000) can't call 
#      your API (localhost:8000) due to browser security rules
from fastapi.middleware.cors import CORSMiddleware

# ============================================================
# Initialize the FastAPI Application
# ============================================================
app = FastAPI(
    title="Unified Resume Builder API",
    description="ATS scoring, keyword analysis, and AI-powered resume optimization",
    version="0.1.0",
)

# ============================================================
# Configure CORS (Allow Frontend to Connect)
# ============================================================
# WHY: During development, your frontend runs on a different port
#      than your backend. CORS rules control who can access your API.
app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:3000",  # React dev server
        "http://127.0.0.1:3000",
    ],
    allow_credentials=True,      # Allow cookies
    allow_methods=["*"],         # Allow all HTTP methods (GET, POST, etc.)
    allow_headers=["*"],         # Allow all headers
)

# ============================================================
# Health Check Endpoint
# ============================================================
# WHY: A simple endpoint to verify the API is running.
#      Useful for monitoring and deployment checks.
@app.get("/")
async def root():
    """
    Root endpoint - returns a welcome message.
    Use this to verify the API is running.
    """
    return {
        "message": "Welcome to the Unified Resume Builder API",
        "status": "healthy",
        "version": "0.1.0"
    }

@app.get("/health")
async def health_check():
    """
    Health check endpoint for monitoring tools.
    Returns 200 OK if the service is running.
    """
    return {"status": "ok"}

# ============================================================
# Run the Server (for development)
# ============================================================
# WHY: This block only runs when you execute this file directly,
#      not when it's imported by another module.
if __name__ == "__main__":
    import uvicorn
    
    # Run the server on localhost:8000
    # reload=True means the server restarts when you change code
    uvicorn.run("main:app", host="0.0.0.0", port=8000, reload=True)
EOF
```

## Set Up Python Virtual Environment

```bash
# Navigate to the backend folder
cd backend

# Create a virtual environment named 'venv'
# WHY: Isolates your project's Python packages from the global system
python3 -m venv venv

# Activate the virtual environment
# WHY: After activation, 'pip install' only affects this project
source venv/bin/activate    # On Mac/Linux
# OR
# venv\Scripts\activate     # On Windows

# Install all dependencies
pip install -r requirements.txt

# Download the spaCy English language model
# WHY: spaCy needs pre-trained models to understand English text
python -m spacy download en_core_web_sm

# Go back to project root
cd ..
```

⚠️ **BEGINNER WARNING:** You'll see `(venv)` at the start of your terminal prompt when the virtual environment is active. If you open a new terminal, you need to activate it again!
