NEVER bring in context from other projects into a chat that is focused on one specific project. If a session handover mentions multiple projects, ONLY work on the one the user explicitly asked for in THIS chat. Do not reference, suggest, or mention other projects unprompted.

**Why:** User got frustrated when eval-framework status was mixed into an AI Resume Generator chat. Previous session handover contained both projects' context, but the user only asked to work on ResumeAI in this chat. Mentioning eval-framework was confusing and off-topic.

**How to apply:** At the start of each chat, identify which single project the user wants to work on. Ignore all other project context from handovers/memory. Only bring up other projects if the user explicitly asks.
